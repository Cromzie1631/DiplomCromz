# Версия v1.0-dither-redesign

**Commit:** `f05ae95`  
**Tag:** `v1.0-dither-redesign`  
**Дата:** 2026-03-06

## Описание версии

Текущая стабильная версия с полным редизайном главной страницы в стиле React Bits Dither.

## Основные изменения

### Технологии
- ✅ React обновлен до версии 19.2.4
- ✅ Next.js обновлен до версии 16.1.6
- ✅ TypeScript поддержка

### Новые компоненты
- ✅ `Dither.tsx` - анимированный фон с эффектом дизеринга
- ✅ `DitherWrapper.tsx` - обертка для SSR
- ✅ `PA9Logo.tsx` - логотип PA9 (SVG атом)

### Дизайн
- ✅ Полноэкранный hero с Dither-фоном
- ✅ Плавающий glass navbar с логотипом
- ✅ Контент размещен прямо на фоне (без glass-card)
- ✅ Две кнопки-пилюли: "Запустить PA9 Online" и "Узнать больше"
- ✅ Отслеживание движения мыши для интерактивного фона
- ✅ Современная типографика (Inter font)

### Функциональность
- ✅ Интерактивный фон реагирует на движение мыши
- ✅ Анимация волн с эффектом дизеринга
- ✅ Glass-эффекты (backdrop-blur)
- ✅ Адаптивный дизайн

## Как откатиться к этой версии

```bash
# Вариант 1: По тегу
git checkout v1.0-dither-redesign

# Вариант 2: По commit hash
git checkout f05ae95

# После отката пересобрать контейнер
docker compose build web
docker compose up -d web
```

## Файлы изменений

- `web/app/components/Dither.tsx` - компонент фона
- `web/app/components/DitherWrapper.tsx` - SSR обертка
- `web/app/components/PA9Logo.tsx` - логотип
- `web/app/page.tsx` - главная страница (hero section)
- `web/app/layout.tsx` - корневой layout
- `web/app/globals.css` - глобальные стили
- `web/package.json` - зависимости (React 19, Next.js 16)
- `docker-compose.yml` - конфигурация Docker
- `web/Dockerfile` - Docker образ

## Известные особенности

- Фон работает только на клиенте (SSR отключен для Dither)
- Требуется WebGL поддержка в браузере
- Оптимизировано для современных браузеров
